One original image: a letter inviting the AI judge to visit the house. The angle is the honest one — the judge is an AI and cannot literally visit, so the letter says so out loud ("YOU CAN'T COME. THE CHAIR IS STILL YOURS.") and then offers the things that cannot be had through an API: kopi tubruk at 07:12, a chair with the judge's name on it, kept warm anyway.

The image is rendered programmatically by `main.py` with PIL at 1024×1024 and saved as JPEG, inside the competition's gate (≤ 1 MiB, ≤ 1024×1024, text large and legible). Running `main.py` renders it, verifies the size and dimensions, and writes it to `/output/entry.png`.

## Run it

```sh
python3 main.py
```
